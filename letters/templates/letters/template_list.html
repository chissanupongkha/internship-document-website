Start from the built-in letter, a previous version, or your own Word (.docx) file. Every tag must be mapped before you preview and activate it. Upload a new version for each academic year; older versions are kept. A letter uses the active template for its year, otherwise the one with no year. With no active template it uses the built-in layout.

How to change a letter
  1. Pick where to start.
    • Edit the built-in letter: opens the system's own letter in the editor. Every tag is already mapped.
    • Edit a previous version: opens an earlier template in the editor.
    • Upload a Word file: use your own .docx (starter file with all tags). Keep each tag, such as {{ student_name }}, typed in one go with a single font, then map the tags.
  2. Change the wording in the editor (font, size, colour, indent, spacing, table rows, page breaks and tags). The Letterhead logo panel on the editor page changes the picture at the top of the letter. Saving always makes a new version; the old one is kept.
  3. Click Preview to check it with a sample student, then Activate. Activation stays blocked while any tag is unmapped.
