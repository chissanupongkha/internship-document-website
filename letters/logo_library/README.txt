Put the official Mahidol logo images here (PNG or JPG), then run:

    python manage.py load_logos

Download them from https://mahidol.ac.th/th/logo-corporate-identity/
(press the PNG button, right-click the image, Save image as).

Keep the file names the site gives, for example:
  logo-MU_Color-2.png         -> "Mahidol - letterhead mark (colour)"
  logo-MU_black-white-2.png   -> "Mahidol - letterhead mark (black)"
  Logo1.png, Logo3.png ...    -> "Mahidol - Logo1" ...
The command can be run again at any time; logos already loaded are skipped.
