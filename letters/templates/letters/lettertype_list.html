Letter Types & Mappings

Define letter categories and manage how spreadsheet text links to each letter type.

How this page works

  1. Each row below is a letter type. The Display Name is the Thai title shown to staff, and the Slug is the short internal code (no need to change it).
  2. Staff fill in a letter type column in the uploaded spreadsheet. The system reads that wording and decides which letter type it means. Mapped Spreadsheet Text Values are the wordings you have taught it to recognise for each type.
  3. If a type shows "No spreadsheet text mapped", nothing is wrong: the system still recognises the built-in wording (and the type name itself). Add a mapping only when staff use different wording.
  4. If an uploaded wording is not recognised, it appears in the yellow box at the top. Choose its letter type there and press Map.
  5. To create a new letter type, go to Document templates → Create template. It creates the type, its template and its matching wording together.
